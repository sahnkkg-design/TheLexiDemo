# TheLexi

A Chrome extension that makes online reading easier. Drag-select a sentence on any page and TheLexi shows a simpler version, plus an explanation if you need it. Drag or double click for unfamiliar words to instantly get the definition.


## How it works
1. Select a word or sentence while reading.
2. TheLexi sends the text to an AI model through a small server I set up.
3. You get a simplified version and an explanation, right on the page.
4. Save it as a flashcard to review later.

The AI key stays on the server and is never inside the extension.

## Why I built it
I noticed how often people skip over words and sentences they don't understand while reading online, because looking them up breaks their focus. I wanted to make that quick and easily accessible 

## Built with
- Chrome extension (browser add-on)
- AI model for simplifying and explaining text
- Built solo using AI-assisted development tools on Replit
